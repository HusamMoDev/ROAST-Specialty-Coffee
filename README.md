A modern, high-converting, and responsive web platform prototype designed for **ROAST Specialty Coffee & Cha Cha Chai** in Dubai, UAE. Built to drive direct customer ordering, eliminate third-party delivery commissions, and showcase coffee offerings and branch locations.

---

## 📌 Project Overview (نظرة عامة)

تم تصميم وتطوير هذه المنصة كنموذج أولي تفاعلي عالي الأداء لقطاع الضيافة والمقاهي المختصة في دبي، مع التركيز على:
1. **زيادة المبيعات المباشرة:** تمكين العملاء من الطلب مباشرة لتوفير عمولات تطبيقات التوصيل (15% - 20%).
2. **تجربة مستخدم سريعة وخفيفة (Mobile-First):** تصفح فوري وسلس دون الحاجة لتحميل ملفات PDF بطيئة.
3. **تكامل مباشر مع واتساب:** تحويل اختيارات العميل إلى رسالة طلب فورية ومنسقة إلى الفرع.

---

## ✨ Key Features (أبرز المميزات)

- **🎨 Modern Visual Identity:** Clean, sleek theme featuring Deep Navy (`#13253B`) and Warm Accent Orange (`#E67E22`) with subtle shadow depths and micro-interactions.
- **📜 Smart Interactive Menu:** Clean 4-card showcase displaying specialty coffee brews (V60 Geisha, Spanish Latte, Flat White) and desserts priced in AED.
- **🛵 Zero-Commission Direct Ordering Banner:** Dedicated high-impact section highlighting speed, direct ordering savings, and flexible payment options.
- **📍 Branch Locator Grid:** Structured 6-location directory covering key UAE spots:
  - Dubai Science Park (Production & Roastery Hub)
  - Downtown Dubai (Mohammed Bin Rashid Blvd)
  - Deira
  - Al Barsha 1
  - Dubai Marina
  - Abu Dhabi (Airport Rd)
- **💬 Direct WhatsApp Automation:** Dynamic order buttons that generate pre-filled WhatsApp messages with selected items and quantities.
- **📱 Fully Responsive (RTL Support):** Pixel-perfect across mobile, tablet, and desktop viewports using Google Tajawal typography.

---

## 🛠️ Tech Stack (التقنيات المستخدمة)

- **Frontend:** Semantic HTML5, Modern CSS3 (Grid, Flexbox, CSS Variables), Vanilla JavaScript.
- **Typography:** [Google Fonts — Tajawal](https://fonts.google.com/specimen/Tajawal).
- **Icons & Assets:** High-resolution uncompressed imagery optimized for web performance.
